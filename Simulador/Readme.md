Simulador(com métricas compartilhadas entre todos): Possui um sistema simples de renda fixa, com X opções diferentes, cada uma com um tempo de validade e uma taxa de rendimento fixa, correspondente à uma taxa variável (funcionamento da SELIC) 
Também possui uma área de investimentos variáveis, baseado no sistema utilizado em cookie clicker (cada ação tem uma TREND associada a ela (aumento, redução, estável, caótica). A trend pode ser vista como um valor base pequeno que, a cada atualização de preços, é aplicada à ação. Após aplicação do valor base, é aplicado, na mesma atualização, um valor aleatório que pode ser muito maior do que o valor da trend, fazendo com que as flutuações pareçam caóticas, mas que convirjam para um valor. Após certas quantidades de atualizações, as trends das ações mudam (ou não))
